# Clayface_aScene

영화 「클레이페이스」의 한 장면을 오마주한 변장 러너 웹게임입니다.

**플레이:** https://kimbyeonghoon51.github.io/Clayface_aScene/ · **밸런스 테이블:** https://kimbyeonghoon51.github.io/Clayface_aScene/balance.html

## 개요
| 항목 | 내용 |
|---|---|
| 장르 | 변장 러너 (쿠키런식 제자리 걷기 + 모습 저장·변신 퍼즐) + 연출형 보스전 |
| 플랫폼 | 웹 브라우저 (PC, 키보드) |
| 플레이 시간 | 약 6분 (스테이지 4개 + 엔딩) |
| 분위기 | 공포 · 누아르 — 비 내리는 밤, 붉은 역광, 실루엣 |

**이야기** — 배우 맷 헤이건은 마피아 보스 마르코스에게 얼굴을 처참하게 훼손당했습니다. 얼굴을 되찾으려 투여한 약물의 부작용으로 얼굴과 몸을 진흙처럼 바꾸는 괴물, 클레이페이스가 된 그는 복수를 위해 비 내리는 밤 마르코스의 클럽으로 향합니다.

**기획 의도** — 지나가는 사람들의 모습을 저장해 두었다가, 위기가 닥칠 때마다 그 위기를 벗어나는 데 필요한 사람으로 변신해 빠져나가는 게임.

## 핵심 규칙
- 사람들이 오른쪽에서 2~4명씩 팀을 지어 걸어옵니다. ← →로 고르고 Space로 모습을 저장하며, A S D F로 변신합니다.
- 저장 칸은 4칸이고 비울 수 없습니다. 변신 쿨타임은 2초이며, 원래 모습으로 돌아가는 키는 없습니다.
- 길을 막아선 사람(문지기·경비원·경찰) 앞에 **도착한 순간의 모습**으로 통과가 결정됩니다.
- 2스테이지부터 변신 6초 뒤 얼굴이 굳기 시작해 10초에 변장이 무너집니다. 같은 키로 다시 빚을 수 있습니다.
- 스테이지가 끝날 때, 2·4스테이지는 검문을 지날 때마다 저장 칸이 비워집니다.

## 스테이지
| 스테이지 | 구성 | 통과 조건 |
|---|---|---|
| 1 클럽 가는 길 | 20명 · 27초 · 튜토리얼 | 문지기의 드레스코드 — 정장이나 드레스 |
| 2 클럽 내부 | 40명 · 검문 3번 → 계단에서 괴물로 깨어나는 연출 | 바 입구: 바텐더 · 복도 입구: 젊은 마피아 부하 · 계단 입구: 나이 든 마피아 부하 |
| 3 보스 방 | 배경음악 길이(약 85초)에 맞춘 연출 | 경호원 웨이브 6종(키 하나 · 3개 순서 · 꾹 누르기 · 두 키 동시 · 연타 · 타이밍 링) → SPACE 연타로 덩치를 키워 연인과 마르코스를 한입에 |
| 4 탈출 | 25명 · 검문 2번 · 돌발 순찰 2번 | 바 출구: 경찰이나 민간인 · 정문: 경찰만 · 순찰: 마피아나 원래 모습이면 체포 |
| 엔딩 | 비 오는 거리 | 물웅덩이에 비친 괴물의 눈 → THE END |

## 조작
| 키 | 동작 |
|---|---|
| Space | 시작 · 저장 · 다음 · GAME OVER에서 다시 시작 |
| ← → | 다가오는 사람 선택 |
| A S D F | 변신 / 3스테이지에서는 화면에 뜨는 키 |
| P · Esc | 일시정지 |
| H · ? 버튼 | 조작법·규칙 |
| M · 🔊 버튼 | 소리 켜기·끄기 |

## 설계 포인트
- **변신할 이유가 계속 생기게** — 검문을 여러 번 두고, 구간마다 필요한 모습을 바꾸고, 칸을 비우고, 변장이 굳어 무너지게 해 “저장하고 꺼내 쓰는” 반복을 만들었습니다.
- **한눈에 구분되는 옷** — 어두운 실루엣 안에서도 몇 초 안에 알아보도록 종류마다 옷 모양과 색이 겹치지 않게 설계했습니다 (정장에는 넥타이 없음, 평상복에는 드레스와 헷갈리는 색 없음, 고참 마피아는 회색 머리·주름·콧수염).
- **설명 대신 독백** — 화면에 설명 문구를 두지 않고, 주인공의 독백과 말풍선으로 어디로 가고 어떤 얼굴이 필요한지 알려 줍니다.
- **괴물은 아껴서 공개** — 타이틀과 계단에서는 검은 실루엣으로만, 보스 방 문이 부서지는 순간 처음 드러냅니다.
- **대사도 밸런스** — 수치와 모든 대사를 `balance.js`에 모으고, `balance.html` 표에서 고쳐 바로 확인할 수 있게 했습니다. [balance.js 내보내기]로 받은 파일을 저장소에 넣으면 모두에게 적용됩니다.

## 만든 방식
- HTML 파일 하나(Canvas 2D), 외부 라이브러리·이미지 파일 없음. 캐릭터는 코드로 그린 실루엣 누아르(어둡게 68% + 붉은·푸른 림라이트)
- 효과음은 Web Audio로 합성, 배경음악은 영화 OST
- 자동 플레이 봇(`#bot`)과 시뮬레이션(`#sim=초`)으로 스테이지마다 클리어를 확인한 뒤 GitHub Pages에 배포

비상업적 팬 오마주 프로젝트입니다.
