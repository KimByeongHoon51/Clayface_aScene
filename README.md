# Clayface_aScene

영화 「클레이페이스」의 한 장면을 오마주한 웹게임입니다. 얼굴과 모습을 자유자재로 바꾸는 주인공이 복수를 위해 클럽에 잠입합니다.

**플레이:** https://kimbyeonghoon51.github.io/Clayface_aScene/

## 진행 상황
- STAGE 1 클럽 가는 길 — 완성
- STAGE 2 클럽 내부 — 완성 (댄스홀 → 바 → 복도 → 계단, 계단을 오르며 괴물로 변함)
- STAGE 3 보스 방 · STAGE 4 탈출 — 제작 중

## 조작
| 키 | 동작 |
|---|---|
| Space | 시작 / 선택한 사람의 모습 저장 |
| ← → | 다가오는 사람 선택 |
| A S D F | 저장한 모습으로 변신 (쿨타임 3초) |
| ? 버튼 / H | 조작법·규칙 |
| P / Esc | 일시정지 |
| 🔊 버튼 / M | 소리 켜기·끄기 |
| R | 이 스테이지 처음부터 |

## 규칙
- 지나가는 사람의 모습을 A S D F 칸에 최대 4명까지 저장할 수 있고, 플레이어를 지나간 사람은 저장할 수 없습니다.
- 길을 막아선 사람 앞에 도착한 순간의 모습으로 통과가 결정됩니다.
- 변신하고 15초가 지나면 얼굴이 굳기 시작해 24초에 변장이 무너집니다. 같은 키를 다시 눌러 새로 빚을 수 있습니다.
- 스테이지가 끝나면 변신이 풀리고 저장한 모습도 모두 사라집니다.

| 스테이지 | 사람 수 · 시간 | 통과 조건 |
|---|---|---|
| 1 클럽 가는 길 | 20명 · 30초 | 문지기의 드레스코드 — 남자는 정장, 여자는 드레스 |
| 2 클럽 내부 | 40명 · 약 80초 | 검문 3번 — 바 입구·복도 입구: 직원(바텐더) · 계단 입구: 마피아 부하(검은 정장, 얼굴 흉터·대머리·총) |

## 만든 방식
- HTML 파일 하나(Canvas 2D)로 만들었고, 외부 라이브러리나 이미지 파일은 쓰지 않았습니다.
- 캐릭터는 코드로 그린 실루엣 누아르 스타일(역광 + 붉은 림라이트)입니다.
- 효과음과 배경음은 Web Audio로 직접 합성했습니다.

비상업적 팬 오마주 프로젝트입니다.
