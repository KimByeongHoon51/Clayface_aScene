# Clayface_aScene

영화 「클레이페이스」의 한 장면을 오마주한 웹게임입니다. 마르코스에게 얼굴을 처참하게 훼손당한 배우 맷 헤이건은 약물의 부작용으로 얼굴과 모습을 자유자재로 바꾸는 진흙 괴물이 되었고, 복수를 위해 마르코스의 클럽에 잠입합니다.

**플레이:** https://kimbyeonghoon51.github.io/Clayface_aScene/

## 진행 상황
- STAGE 1 클럽 가는 길 — 완성
- STAGE 2 클럽 내부 — 완성 (댄스홀 → 바 → 복도 → 계단, 계단을 오르며 괴물로 변함)
- STAGE 3 보스 방 — 완성 (클레이페이스 첫 공개, 경호원 쳐내기, 커진 괴물이 마르코스와 연인을 한입에 삼키는 연출)
- STAGE 4 탈출 — 완성 (경찰 통제선을 뚫고 정문으로, 돌발 순찰, 빗속으로 사라지는 엔딩)

## 조작
| 키 | 동작 |
|---|---|
| Space | 시작 / 선택한 사람의 모습 저장 |
| ← → | 다가오는 사람 선택 |
| A S D F | 저장한 모습으로 변신 (쿨타임 2초) |
| ? 버튼 / H | 조작법·규칙 |
| P / Esc | 일시정지 (Space·Esc로 계속) |
| 🔊 버튼 / M | 소리 켜기·끄기 |
| Space (GAME OVER) | 이 스테이지 처음부터 |

## 규칙
- 지나가는 사람의 모습을 A S D F 칸에 최대 4명까지 저장할 수 있고, 플레이어를 지나간 사람은 저장할 수 없습니다.
- 길을 막아선 사람 앞에 도착한 순간의 모습으로 통과가 결정됩니다.
- (2스테이지부터) 변신하고 6초가 지나면 얼굴이 굳기 시작해 10초에 변장이 무너집니다. 같은 키를 다시 눌러 새로 빚을 수 있습니다.
- 스테이지가 끝나면 변신이 풀리고 저장한 모습도 모두 사라집니다.

| 스테이지 | 사람 수 · 시간 | 통과 조건 |
|---|---|---|
| 1 클럽 가는 길 | 20명 · 27초 | 문지기의 드레스코드 — 남자는 정장, 여자는 드레스 |
| 2 클럽 내부 | 40명 · 약 70초 | 검문 3번 — 바 입구: 직원(바텐더) · 복도 입구: 젊은 마피아 부하 · 계단 입구: 나이 든 마피아 부하(회색 머리). 검문을 지날 때마다 저장 칸 초기화 |
| 3 보스 방 | 연출 약 45초 | 화면에 뜨는 키(A S D F)를 1.5초 안에 눌러 경호원 쳐내기 ×2, SPACE 연타로 덩치를 키워 한 명씩 한입에 삼키기 |
| 4 탈출 | 27명 · 약 55초 | 바 출구: 경찰복 · 정문 통제선: 일반 손님(경찰 모습이면 붙잡힘) · 돌발 순찰 2번: 마피아나 원래 모습이면 체포 |

## 만든 방식
- HTML 파일 하나(Canvas 2D)로 만들었고, 외부 라이브러리나 이미지 파일은 쓰지 않았습니다.
- 캐릭터는 코드로 그린 실루엣 누아르 스타일(역광 + 붉은 림라이트)입니다.
- 효과음과 배경음은 Web Audio로 직접 합성했습니다.
